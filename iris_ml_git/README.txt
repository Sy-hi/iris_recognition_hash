
# Iris Recognition System

This project is a deep learning-based iris recognition system. It includes segmentation using U-Net, feature extraction with ArcFace-enhanced EfficientNet, and binary hashing for fast identity matching.

---

## Main Scripts

1. **'train_model.py'**  
   Trains a U-Net model for iris segmentation using BCEWithLogitsLoss and DiceLoss. Includes preprocessing and augmentation.

2. **'seg.py'**  
   Perform iris segmentation using a trained U-Net model and outputs transparent masked iris images.

3. **'train_arcface_model_strong_v3.py'**  
   Trains a multi-task ArcFace-based iris recognition model with hash output, ArcFace classification, and center/triplet loss.

4. **'infer_identity_from_image.py'**  
   Runs the full pipeline: segmentation → normalization → feature encoding → identity inference using Hamming distance.

5. **'train_model 2.py'**  
   Trains a U-Net model for iris segmentation using BCEWithLogitsLoss and DiceLoss. Includes preprocessing and augmentation. A try to segment Dataset 2 but failed.

6. **'seg 2.py'**  
   Perform iris segmentation using a trained U-Net model and outputs transparent masked iris images. A try to segment Dataset 2 but failed.

---

## Support Modules

- 'arcface_iris_model.py' – EfficientNet + ArcFace + HashNet architecture
- 'center_loss.py' – Center loss for intra-class compactness
- 'losses_v2.py' – Multi-task loss: ArcFace, Triplet, Hash loss
- 'evaluate_accuracy_and_hamming_v4.py – Accuracy evaluation and histogram plotting
- 'save_encodings_and_analyze.py' – Save and compare iris encodings
- 'threshold_search.py' – Best threshold search for 1:N matching
- 'tsne_visualizer.py' – Visualize binary hash distribution with t-SNE
- 'batch_normalization_half.py' – Normalize iris and crop lower half
- 'save_image_encodings_both.py' – Save CSV + PKL iris encodings per image

- 'batch_normalization_full.py' – Normalize iris(not used)
- 'check cuda.py' – Check CUDA version
